# T01–T04 prototype playtest: participant guide

This session tests the QA investigation experience, not the participant's ability.
Explore Shoply as you normally would, read each Ticket, and decide what Evidence and
Report to submit. There is no penalty for exploratory clicks. You may say what you
expect, notice, or find confusing while playing.

## Start

The facilitator will provide the app URL and a fresh browser save. Begin at `/start`,
select **Start Work**, and continue from the Company Dashboard through the available
Tickets. Please do not read the repository's development test checklist before the
session; it contains the expected defect locations.

Work through the available Tickets in order. For each one, explore the fake Shoply
site, capture Evidence if useful, submit a Report, read the Review, and return to the
Dashboard. Try the tools that become available as you progress. If you get stuck,
tell the facilitator what you were trying to do before asking for a hint.

## After playing

Answer these six questions in your own words. Examples from particular moments are
more useful than a score alone. It is fine to answer "no" or "not sure".

1. 이슈를 찾는 과정이 재미있는가?
2. Shoply가 믿을 수 있는 서비스처럼 느껴지는가?
3. 정상 동작과 결함을 구분할 수 있는가?
4. 재현과 Evidence 확보가 만족스러운가?
5. Report가 서류 작업이 아니라 Gameplay로 느껴지는가?
6. 다음 Ticket을 열고 싶은가?

The facilitator may ask which screen or interaction led to each answer. The project
owner, not the participant, makes the later content-production decision.
